# 微信 BP 收件适配器

这个模块复用本机已经跑通的 `wechat-content-router-windows`，但不复制私人知识库、微信账号标识、Cookie、历史消息或路由器的私有配置。

工作流：

1. 在 Cofound BP Desk 的导入页建立一次安全基线；已有微信文件只登记签名，不导入。
2. 给自己的文件传输助手发送 `存入项目库`，随后发送 BP、财务模型、尽调材料、合同订单、行业资料、会议纪要或其它项目附件。
3. 回到导入页点击“检查并接收”。本地接收器只保留经过 `filehelper` 范围验证的口令 ID 和附件文件名。
4. 文件名与本机微信下载目录中的新增文件精确匹配后，才进入 SHA-256 去重和资料分类。BP 进入分析和版本流程；其它资料自动关联已有项目，无法判断归属的进入“待归档”。

扫描微信进程可能需要 Windows 管理员权限。失败时不会退回读取其它聊天，也不会把任何微信内容上传到 Vercel。

Vercel 只承接管理员明确选择发布的项目快照；微信接收、原始 BP 存储和分析仍在本机进行。
