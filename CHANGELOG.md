# Changelog

All notable public changes are documented here. This project follows semantic
versioning for the application. The Codex Plugin keeps a separate compatibility
version in `plugins/cofound-bp-desk/.codex-plugin/plugin.json`.

## 1.3.0 - 2026-08-25

Initial public-source release.

### Added

- Codex-first local BP workbench and 12 bundled Skills.
- Evidence-bound facts, analysis provenance, stale detection and management
  status separation.
- Local recycle bin, material intake, WeChat inbox and Feishu team inbox.
- Selective Vercel sharing with six-digit access code, inline preview and
  annotations.
- Optional CleanTech financial audit, read-only Shanghai policy match and
  European/Brazilian project-opportunity match tools.
- Product feedback diagnosis and human-reviewed iteration workflow.

### Security and release

- Fresh public history excludes local data, real BP files, credentials, Feishu
  locators, Vercel bindings, internal reports and legacy acceptance artifacts.
- Added public privacy, security, contribution and architecture documentation.
