# 安全边界与可选部署

## Vercel Lite 已实现

- 本机项目默认不上传，只有明确发布的字段和文件进入云端。
- 每个项目使用独立的 192-bit 随机分享令牌；不存在公开项目目录。
- 分享令牌校验在 API 查询层执行，错误令牌返回 404。
- 选中文件进入 Vercel Private Blob，Blob 原始地址不交给浏览器。
- 文件只提供 `inline` 查看响应；页面无下载按钮、无下载 API。
- 批注限定在对应项目、字段或文件内，带回复关系、解决状态和 revision。
- 分享可暂停；暂停后项目、文件与批注接口统一不可访问。
- 管理员到云端的同步使用单独随机密钥，不使用 Codex 登录凭据。

“关闭下载”减少误操作，但不能阻止截图、录屏或技术性保存。真正需要更强防泄漏时，应增加实名账号、到期策略、访问审计和服务端动态水印；极高保密材料不应通过普通网页分享。

## 默认 Vercel Lite

需要 Vercel 项目、Neon Postgres 和 Vercel Private Blob，不需要 Docker、持久磁盘、常驻 worker、LibreOffice 或云端 OCR。所有重分析仍在本机执行，网站只存已发布快照。

具体步骤见 [VERCEL_LITE_DEPLOYMENT.md](VERCEL_LITE_DEPLOYMENT.md)。

## 可选公司私有化完整版

仓库原有的账号、邀请、字段/文件授权、高保密预览、下载申请、一次性水印文件、审计和任务队列继续保留。只有公司以后确认需要这套高保密资料室时，才使用 `Dockerfile` / `docker-compose.yml` 部署到带加密持久磁盘的公司云服务器。

那时还需要企业确定域名与 TLS、云区域、备份周期、数据保留、离职账号停用和邮件出口。它们不是 Vercel Lite 首轮测试的前置条件。
